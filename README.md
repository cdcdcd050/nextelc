# nextelc

**넥스트전자 (NEXTELC)** 사이트 — GitHub Pages 로 뜬다.

> <https://cdcdcd050.github.io/nextelc/>

## 무엇인가

**구글 개발자 인증의 「웹사이트」 칸에 넣을 주소**가 필요해서 만든 페이지다.
그것이 이 사이트가 있는 이유의 전부다 — 상호가 실재하고 연락이 닿는다는 것을 보이면 된다.

파일은 `index.html` **한 장**이고 소개와 문의처뿐이다.
**영어가 앞에 서고 한국어가 그 뒤에 붙는다** — 해외 심사에서 읽히는 자리라서다.

## 고칠 때

⚠️⚠️ **앱을 소개하는 자리가 아니다**(2026-08-31 지정 "굳이 앱을 소개할 필요는 없다").
앱 카드·스크린샷·기능 설명을 도로 넣지 말 것 — 앱 이야기는 **각 앱의 제 페이지**와
**스토어 등록정보**가 맡는다.

⚠️ **「1인」이라 적지 말 것**(같은 날 지정) — 사람 수를 말하는 자리가 아니다.

⚠️ **사업자등록번호·주소·전화번호는 일부러 안 적었다**(같은 날 지정 "상호·이메일만").
적혀 있는 것은 **상호 · 국가 · 이메일** 셋이다. 심사가 「이 사이트가 그 사업자의
것인가」를 되물으면 `#contact` 의 `<dl>` 에 줄을 더하는 것이 그 답이다.

⚠️ **외부 스크립트·글꼴·이미지를 안 쓴다** — 전부 인라인이라 이 파일 하나가 곧 사이트다.
남의 그림도 안 쓴다(라이선스 고지가 따라붙지 않게 두는 것이 이 페이지에 맞다).
