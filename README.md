# nextelc

**넥스트전자 (NEXTELC)** 공식 사이트 — GitHub Pages 로 뜬다.

> <https://cdcdcd050.github.io/nextelc/>

## 무엇인가

파일 한 장(`index.html`)짜리 정적 사이트다. 사업자 소개 · 만드는 앱 · 개인정보 방침 ·
문의처를 담는다. **영어가 앞에 서고 한국어가 그 뒤에 붙는다** — 해외 스토어 심사에서
읽히는 자리라서다.

이 주소는 **구글 플레이 개발자 인증의 「웹사이트」 칸**에 넣는 그 주소이고,
스토어 등록정보의 `Website` 도 이것을 가리킨다.

## 고칠 때

- 파일은 `index.html` **하나**다. 외부 스크립트·글꼴·이미지를 안 쓴다(전부 인라인).
- **앱을 하나 더 내면 `<section id="apps">` 안에 `.app` 카드를 하나 더 둔다.**
  카드 안의 그림은 인라인 SVG 다(lucide 파생 · ISC).
- 앱의 **개인정보처리방침은 여기 안 적는다** — 앱마다 제 페이지에 있고 여기서는 링크만 건다.
  채터링 것은 <https://cdcdcd050.github.io/chattering/> 다.
- ⚠️ **사업자등록번호·주소·전화번호는 일부러 안 적었다**(2026-08-31 지정).
  적을 일이 생기면 `#contact` 의 `<dl>` 에 줄을 더한다.
- ⚠️ **문의 이메일은 채터링 방침 페이지의 것과 같아야 한다**(`cdcdcd050@naver.com`) —
  스토어 심사가 둘을 견준다. 한쪽만 고치지 말 것.
